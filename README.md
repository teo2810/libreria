# libreria

Pattern UI riutilizzabili: tab, dock, FAB, chip, motion, download.

Apri `index.html` per le anteprime. Ogni card ha un **id** — cita quello per riprodurre il pattern.

| id | pattern |
|---|---|
| `dl-wave` | bottone download circolare: anello, onda, %, check / drop |
| `tab-pill-fab` | barra tab vetro, pillola, FAB centrale |
| `dock-bead` | dock basso, perlina, icona attiva |
| `segmented-pill` | switch a due opzioni |
| `chips` | chip filtro |
| `motion-tokens` | float, pulse, twinkle, tap |
| `fab-expand` | FAB che si allarga in input |
| `ripple-sheet` | ripple + pannello |
| `feedback` | pop / pulse / shake |

Demo standalone: `demos/dl-wave.html`.

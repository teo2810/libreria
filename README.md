# libreria

Pattern UI riutilizzabili. Apri `index.html` o le demo in `demos/`.
Cita l'**id** per riprodurre il pattern.

| id | pattern |
|---|---|
| `dl-wave` | download circolare: anello, onda, %, check/fail |
| `drop-fusion` | goccia piccola si stacca e si riattacca |
| `col-split` | colonna che si sdoppia in due pannelli |
| `path-tension` | path SVG che pulsa come tensione superficiale |
| `sun-moon` | mezzaluna → sole, raggi a goccia |
| `save-morph` | floppy → spunta verde |
| `import-arrow` | freccia gommosa dentro il box |
| `export-arrow` | freccia che schizza fuori dal box |
| `tab-pill-fab` | tab vetro + FAB |
| `dock-bead` | dock perlina |
| `segmented-pill` | switch |
| `chips` | chip filtro |
| `motion-tokens` | float / pulse / tap |
| `fab-expand` | FAB → input |
| `ripple-sheet` | ripple + pannello |
| `feedback` | pop / pulse / shake |

Icone SVG: `demos/svg-icons.html`.
